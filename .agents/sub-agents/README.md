# Sub-agent roster

These profiles describe focused roles. The root agent remains responsible for orchestration, shared files, integration, and the final user report.

- `orchestrator.agent.md` routes work and enforces the completion loop.
- `improvement-qa.bot.md` repairs requirements and acceptance documentation before implementation.
- `developer.agent.md` owns approved implementation and execution of checks.
- `kafka-domain.agent.md` owns pure Kafka semantics and scenarios.
- `kafka-reviewer.agent.md` performs read-only Kafka semantic and teaching-accuracy review.
- `visualization.agent.md` owns React/Next.js/Tailwind presentation.
- `test-engineer.agent.md` owns tests and test utilities.
- `reviewer.agent.md` produces read-only findings before fixes.

No profile grants permission to edit another agent's ownership area without an orchestrator handoff.
